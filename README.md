# 🚀 AI Coding Profile Analyzer & Adaptive DSA Coach

An AI-powered platform that analyzes real coding activity from platforms like **LeetCode and Codeforces** and converts it into a personalized DSA learning plan.

Instead of simply showing how many problems a user has solved, the system analyzes **topics, difficulty, solving patterns, contests, consistency and weaknesses** to recommend what the user should learn, practice and revise next.

## 🎯 Problem

Students practice DSA across multiple platforms, but their progress is often fragmented.

Common problems include:

* Not knowing which topics are actually weak
* Spending too much time deciding what problem to solve next
* Practicing random problems without a structured path
* Repeating the same mistakes
* Difficulty tracking progress across multiple platforms
* Getting solutions too quickly instead of learning problem-solving patterns

## 💡 Solution

This project acts as an **adaptive DSA training system**.

It:

1. Fetches real coding-platform profile data
2. Normalizes data from different platforms
3. Analyzes coding performance
4. Detects strengths and weaknesses
5. Recommends personalized problems
6. Creates learning paths
7. Provides progressive hints
8. Tracks revision and progress
9. Provides AI-powered coaching
10. Helps users understand algorithms through visualizations

---

## ✨ Features

### 👤 Real Coding Profile Analysis

Connect supported coding profiles and analyze real activity such as:

* Problems solved
* Difficulty distribution
* Topics
* Submission history
* Contest performance
* Rating
* Coding consistency

The application is designed to avoid fake or hardcoded profile statistics.
